CONVENTIONS
Every entity: 
id: UUID, created_at, updated_at
 (omitted above). Aggregates are the transaction boundaries — nothing outside an aggregate is written in the same commit. Value objects cross the API as Pydantic models and are stored as JSONB on their parent. Services depend on interfaces (
LLMClient, TTSBackend
) so models swap without domain changes.
